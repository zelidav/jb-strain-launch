# JBD NY Drop 1 — Flower & Pre-Roll Launch Page

Single-page GH Pages site for the Jerome Baker Designs NY 2026 Drop 1 flower lineup. Designed for marketing, PR, and sales/budtender use.

## What's in the lineup

**Jars (4):**
- Cherry Gushers — Indica/Hybrid — Barney's Farm × Backpack Boyz
- Haze — Sativa — Greenhouse Seed Co.
- Double Runtz — Hybrid — 7ACRES
- NYC Diesel — Sativa — Exotic Genetix

**Pre-Rolls (3):**
- Hella Jelly — Sativa — Humboldt Seed Co.
- Super Boof — Hybrid — Blockhead
- Grape Nana — Indica — Cannarado Genetics

## Built-in tools

The page has a "Press & Sales Tools" section with one-click copy buttons:
- All 7 strain blurbs
- Full press release
- Budtender quick-ref sheet
- Print / Save PDF

## Deploy

Static site, no build step. Push to `main`, enable Pages on the repo (Settings → Pages → branch: main, folder: /), and the site is live at the GH Pages URL.

## Edit

Everything lives in `index.html` — copy, lineage, terps, breeder links, and the JS-embedded press/budtender text are all in that one file.
